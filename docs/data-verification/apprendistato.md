# Apprendistato — verifica dati

Riferimento normativo: D.Lgs. 81/2015, Capo V (Apprendistato).

## Tipologie di apprendistato

L'app modella l'apprendistato professionalizzante (art. 44 D.Lgs. 81/2015), il più diffuso. Tipicamente dura 3-5 anni in funzione del CCNL applicato.

## Progressione retributiva

La retribuzione è inferiore al livello finale di inquadramento, e cresce per anno di apprendistato. Il D.Lgs. 81/2015 art. 42 c. 5 lett. b) prevede sotto-inquadramento "fino a due livelli inferiori rispetto a quello di destinazione". I CCNL declinano la progressione concretamente.

L'app usa una progressione tipica di mercato per l'apprendistato professionalizzante:

| Anno | % della retribuzione di destinazione |
| ---- | ------------------------------------ |
| 1    | 85%                                  |
| 2    | 90%                                  |
| 3    | 95%                                  |
| 4    | 100%                                 |
| 5    | 100%                                 |

I CCNL specifici (metalmeccanici, commercio, edili, ecc.) possono variare di pochi punti percentuali, in più o in meno, ma la curva è simile.

## Esempio

### Retribuzione di destinazione 28.000 €, durata 3 anni

| Anno | %   | Lordo annuo |
| ---- | --- | ----------- |
| 1    | 85% | 23.800 €    |
| 2    | 90% | 25.200 €    |
| 3    | 95% | 26.600 €    |

## Limiti del modello

- Non personalizza per CCNL specifico.
- Non applica le aliquote contributive ridotte previste per l'apprendistato (5,84% in luogo del 9,19% standard) — quelle vanno usate nel calcolatore stipendio.
- Non modella formazione pagata e fasce contributive INAIL particolari.

## Fonti

- D.Lgs. 81/2015, art. 41-47 — disciplina dell'apprendistato.
- Circolare INPS n. 22/2007 — aliquote contributive ridotte.
- CCNL di settore (Confindustria, Confcommercio, ecc.) — declinazione concreta.
